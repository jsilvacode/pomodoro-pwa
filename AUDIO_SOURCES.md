# Flowmodoro Sounds — audio sources

Flowmodoro uses recorded ambient layers from Freesound under the Creative Commons Zero (CC0 1.0) dedication.

These sources are intentionally kept separate from Spotify music presets. Spotify integration uses public Spotify embeds/playlists; these ambient recordings use the browser audio engine.
